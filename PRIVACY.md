# Privacy Policy — Changelog Fragment Companion

**Effective date:** 2026-08-24

Changelog Fragment Companion is a Gap Hunter Labs plugin for IntelliJ
Platform IDEs. This policy is short because the plugin's design makes it
short: there is nothing to disclose beyond what's below.

## What this plugin collects

**Nothing.** Changelog Fragment Companion does not collect, store,
transmit, or sell any data — no source code, no file contents, no file
paths, no usage analytics, no telemetry, no crash reports, no personally
identifiable information. The issue number, type, and description you
type when creating a fragment are written only to the local file you
create — nowhere else.

## Network access

**None.** Changelog Fragment Companion makes zero network calls during
normal operation.

## Third parties

None. Changelog Fragment Companion has no third-party SDKs, no
analytics libraries, no ad networks, no external towncrier/tool
dependency, no dependencies that phone home.

## Changes to this policy

If this ever changes, this file will be updated and the change will be
noted in the plugin's `CHANGELOG.md`.
